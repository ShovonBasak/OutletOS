What this import does

  • Creates an APPROVED StockInRecord for the selected date (bypasses the OperatingDay staff gate — designed for admin/historic imports).
  • Updates RawStock immediately for all resolved ingredient lines.
  • Ingredient names are matched via supplier alias table, then exact name, then fuzzy (≥ 80 % similarity). Unmatched lines are saved as "Unrecognized" and flagged on the confirm screen.
  • Price data (Rate, VAT, Total) is stored on each line for COGS calculations.
